# mockup

put an app screenshot inside a phone frame, ready for store listings. the frame is drawn on a canvas in your browser — no image assets, no uploads.

- iphone (dynamic island) or android (punch-hole) style
- black, silver or blue frame
- background color or transparent background
- optional caption above the phone
- export at play store 1080×1920 or app store 1290×2796

## run

```sh
npm install && npm run dev
```
